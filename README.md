# Rock Paper Scissors Game

A simple, interactive, and responsive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**.

Challenge the computer, make your move, and see who wins!

## 📌 About the Project

This project is a browser-based implementation of the classic Rock Paper Scissors game.

Players can select Rock, Paper, or Scissors. The computer randomly generates its choice, and the game automatically determines the winner based on the rules.

## ✨ Features

- Interactive Rock, Paper, and Scissors choices.
- Random computer-generated moves.
- Automatic winner detection.
- Real-time score tracking.
- Draw detection.
- Attractive and modern user interface.
- Responsive design for different screen sizes.
- Smooth hover animations and visual effects.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, animations, gradients, and responsive design.
- **JavaScript** – Game logic, event handling, random computer choices, and score management.
- **Google Fonts (Poppins)** – Typography.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/rock-paper-scissors-game.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Select Rock, Paper, or Scissors to start playing!

## 📖 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same option, the game is a draw.
